# Public Roadmap

The FORGE engineering program is organized into a sequence of governance and autonomy capabilities.

This public roadmap intentionally omits sensitive implementation details and does not serve as the authoritative runtime state.

## Foundation

- Governance recovery and baseline
- Knowledge and architecture baseline
- Infrastructure discovery and plane separation
- AI and epistemic governance
- Engineering foundation
- Canonical data and metamodel
- Identity, authority, policy and human gates

## Runtime

- Durable agent runtime
- Governed tool runtime
- Model registry and evaluation
- Multi-agent delegation

## Autonomy

- Engineering autonomy gate
- Interface/provider independence
- Evidence graph and replay
- Security, resilience and supply chain controls
- Autonomous build and engineering workflows
- AI assurance and certification

## Operations

- Continuous AI governance
- Unified control cockpit
- Dogfooding and final autonomy certification

## End-state

The target is a system where an authorized human can provide an objective and authority, and governed agents can:

```text
Plan
→ Delegate
→ Execute
→ Gather Evidence
→ Request Approval when required
→ Deploy
→ Verify
→ Learn
→ Continue
```

while preserving auditability, resumability and human control.
